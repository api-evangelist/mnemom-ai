Mnemom provides a trust plane for the agentic internet, enabling AI agents to declare their capabilities and permissions through signed cards. Their platform offers AIP for reasoning signatures, CLPI for policy enforcement, and the AEGIS gateway that screens model calls. By leveraging cryptographic proofs, Mnemom aims to create a secure, interoperable ecosystem for AI services.

**Areas:** AI · Trust · Security · AgenticInternet · Platform

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Mnemom: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
